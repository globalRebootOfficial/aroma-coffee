
# Aroma Coffee ☕

Адаптивный демонстрационный сайт кофейни.

## Возможности
- Светлая и тёмная темы
- Сохранение выбранной темы
- Адаптивный дизайн
- Фильтрация напитков
- Мобильная навигация

## Технологии
- HTML5
- CSS3
- JavaScript
- GitHub Pages

Учебный проект для портфолио.
